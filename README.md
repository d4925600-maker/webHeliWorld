# webHeliWorld

## HeliWorld

Сайт на Node.js 18+, без внешних npm-зависимостей.

### Первый запуск

1. Создайте `.env` по образцу `.env.example`.
2. Укажите `DEVELOPER_USERNAME` и задайте собственный надёжный `DEVELOPER_PASSWORD`.
3. Запустите `npm start`. Хостинг должен передавать свой порт через `PORT`.

Первый запрос к `/api/state` создаст аккаунт разработчика и файл `data/site-data.json`. Пароль сохраняется только в виде scrypt-хеша. Разработчик может выдавать администраторам доступ. Администраторы могут менять статус сервера и правила.

Для проверки памяти на хостинге подключите постоянный диск к каталогу `data/`. Без постоянного диска данные могут исчезнуть при перезапуске или новом деплое. Сессии пользователей хранятся в памяти процесса и сбрасываются при перезапуске.

Для панели, которая запускает файл напрямую, укажите `index.js` в поле стартового файла. Запуск через `npm start` также поддерживается.

Архив для хостинга не содержит `.env`, `.git` и локальный `data/` с аккаунтами. На чистом хостинге правила и статус по умолчанию — `В разработке`.
